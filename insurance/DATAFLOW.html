9. Known Gaps

Underwriting not wired to UI: nothing moves rows from the three LOB application tables into RAW.APPLICATIONS, so UI submissions never trigger the pipeline.
Document extraction is manual: no task schedules SP_PROCESS_ALL_PENDING_DOCUMENTS; VECTORS.DOCUMENT_CHUNKS is empty.
Two Customer 360 tables: DT_CUSTOMER_360 auto-refreshes, but the app, churn scan and chat read FCT_CUSTOMER_360, which only changes via the legacy SP_BUILD_CUSTOMER_360 and the unstructured-feature task.
Embeddings are insert-only: the MERGE has no WHEN MATCHED clause, so edited fraud indicators are not re-embedded, and the refresh task is suspended.
Event-driven tasks suspended: claims, post-decision, underwriting, health-check and embedding tasks are all suspended; only the daily churn DAG is started.
Unused streams: INTERACTIONS_STREAM and PAYMENTS_STREAM have no consuming task.
